# Viet Trios - Huong dan Phat trien

## Dieu kien

- Python >= 3.10
- Git
- pip hoac uv

## Clone va cai dat

```bash
git clone https://github.com/traingheoblpb-netizen/viet-trios.git
cd viet-trios
python -m venv .venv
source .venv/bin/activate  # hoac .venv\Scripts\activate tren Windows
pip install -e .
```

## Chay test

```bash
pip install pytest
pytest tests/
```

## Dong gop code

1. Fork repo
2. Tao branch `feature/ten_tinh_nang`
3. Cam ket code voi tin nhan ro rang
4. Push va tao pull request

## Cac phuong chap

- Code phai co comment va doc string
- Tat ca ham phai co test
- Pull request can duoc review truoc khi merge
