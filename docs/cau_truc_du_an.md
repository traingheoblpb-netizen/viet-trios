# Huong dan su dung Viet Trios

## Cac lenh co ban

### 1. In ra

```text
in ra "Xin chao"
in ra x
in ra x + 10
```

### 2. Gan bien

```text
x = 5
y = "Xin chao"
z = x + 10
```

### 3. Dieu kien

```text
neu x > 5:
    in ra "x lon hon 5"
```

### 4. Vong lap

```text
lap i trong [1, 2, 3]:
    in ra i
```

### 5. Ham

```text
ham tong(a, b):
    tra_ve a + b

in ra tong(2, 3)
```

### 6. Lop

```text
lop Nguoi:
    ham xin_chao(self, ten):
        in ra "Xin chao " + ten

nguoi = Nguoi()
nguoi.xin_chao("Tuan")
```

## Cac toan tu

- Cong: `+`
- Tru: `-`
- Nhan: `*`
- Chia: `/`
- Chia lay nguyen: `//`
- Lay du: `%`
- Luy thua: `**`

## Cac phep so sanh

- Bang: `==`
- Khac: `!=`
- Lon hon: `>`
- Nho hon: `<`
- Lon hon hoac bang: `>=`
- Nho hon hoac bang: `<=`

## Kieu du lieu

- So nguyen: `5`, `-10`
- So thuc: `3.14`, `-2.5`
- Chuoi: `"Hello"`, `'World'`
- Dung sai: `dung`, `sai`
- Danh sach: `[1, 2, 3]`
- Tu dien: `{"ten": "Tuan"}`

## Vi du toan hoc

```text
x = 10
y = 3
z = x * y
in ra z

neu z > 20:
    in ra "Tich lon hon 20"
```

## Vi du lap

```text
lap so trong [1, 2, 3, 4, 5]:
    in ra so
```
