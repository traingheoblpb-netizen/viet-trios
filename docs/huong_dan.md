# Huong dan su dung Viet Trios

## Cac lenh co ban

### 1. In ra - In tuc cac gia tri

```text
in ra "Xin chao"
in ra x
in ra x + 10
```

### 2. Gan bien - Gan gia tri cho bien

```text
x = 5
y = "Xin chao"
z = x + 10
```

### 3. Neu - Dieu kien if

```text
neu x > 5:
    in ra "x lon hon 5"
```

### 4. Lap - Vong lap for

```text
lap i trong [1, 2, 3]:
    in ra i
```

### 5. Ham - Dinh nghia ham

```text
ham tinh_tong(a, b):
    ket_qua = a + b
    in ra ket_qua
```

## Cac toan tu

- Cong: `+`
- Tru: `-`
- Nhan: `*`
- Chia: `/`
- Chia lay nguyen: `//`
- Lay du: `%`
- Luy thua: `**`

## Cac phep so sanh

- Bang: `==`
- Khac: `!=`
- Lon hon: `>`
- Nho hon: `<`
- Lon hon hoac bang: `>=`
- Nho hon hoac bang: `<=`

## Kieur du lieu

- So nguyen: `5`, `-10`
- So thuc: `3.14`, `-2.5`
- Chuoi: `"Hello"`, `'World'`
- Dung sai: `dung`, `sai`

## Vi du toan hoc

```text
x = 10
y = 3
z = x * y
in ra z

neu z > 20:
    in ra "Tich lon hon 20"
```

## Vi du lap

```text
lap so trong [1, 2, 3, 4, 5]:
    in ra so
```
