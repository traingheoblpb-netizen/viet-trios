# Thu vien chuan Viet Trios

## Mo ta

Thu vien chuan Viet Trios cung cap nhung ham tien ich co ban de xu ly chuoi, danh sach, so lieu va phan tich.

## Ham co ban

### noi_chuoi

```text
noi_chuoi("Xin ", "chao")
```

### doi_chuoi

```text
doi_chuoi(123)
```

### dem_so

```text
dem_so([1, 2, 3])
```

### dao_nguoc

```text
dao_nguoc([1, 2, 3])
```

### loc_so

```text
loc_so([1, "a", 2, "b"])
```
